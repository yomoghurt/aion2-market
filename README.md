# AION2 相場ウォッチ

AION2（グローバル版・Asiaリージョン）の取引所価格を1時間ごとに自動収集し、
**上がりそうなアイテム／下がりそうなアイテム／24時間の値動き**をスマホで見られるサイトです。

- データ元：[aion2.exchange](https://aion2.exchange)（有志による非公式の相場サイト。15分ごと更新、約500品目）
- 日本語のアイテム名：NC公式サイトのアイテム情報
- 収集と公開：GitHub Actions ＋ GitHub Pages（無料）

## 仕組み

```
GitHub Actions（毎時）
  └ collector/collect.py
       ├ aion2.exchange /api/servers, /api/items, /api/items/{id}/prices
       ├ 公開中サイトから前回の履歴を読み戻して追記（最大30日）
       ├ 分析：トレンド・出品数の増減・7日相場との乖離 → スコア
       └ 過去データで「24時間後に予想どおり動いたか」を検証（的中率を表示）
  └ GitHub Pages に site/ ＋ data/ を公開
```

aion2.exchange のAPIはブラウザから直接読めない（CORS非対応）ため、サーバー側で集めて静的ファイルにしています。
データはリポジトリにコミットせず、毎回公開中のサイトから読み戻してマージします。

## スコアの考え方

| 要素 | 重み | 上がりそう側 |
|---|---|---|
| 直近3日のトレンド（対数価格の回帰） | 40% | 上昇中 |
| 出品数の増減（7日中央値比） | 35% | 出品が減っている（品薄） |
| 価格の乖離（7日中央値比） | 25% | 相場より安い |

- 1件だけの外れ出品は前後6時間の中央値と比べて除外
- 履歴が短い品・出品が少ない品・ほとんど売れていない品は確信度を下げる
- |スコア| が 0.15 以上のものを「上がりそう／下がりそう」に表示

**予測は目安です。** 価格は最安出品価格（実際の成約価格ではない）なので、ノイズを含みます。
サイト上部の的中率（50%＝当てずっぽう）を見て、どの程度信用するか判断してください。

## クラフト利益

「🔨 クラフト利益」タブで、レシピごとに **1回クラフトしたときの利益と利益率** を一覧できます。

```
期待売上 = 成功率 × 製品数 × {(1−コンボ率)×製品の相場 + コンボ率×コンボ品の相場} × (1 − 手数料8%)
利益     = 期待売上 − Σ(素材の個数 × 素材の単価)
```

- 素材の単価は「購入」と「自作（その素材のレシピの原価）」の安い方。設定で「すべて購入」にも切り替え可
- 1件だけの極端に高い出品で利益が水増しされないよう、相場は7日中央値の2.5倍を上限にしています
- 取引所に無い素材（NPC販売品など）は内訳画面で単価を入力すると計算に入ります（端末に保存）
- 成功率は熟練度で変わるため設定で調整してください（既定95%）
- 並び順：利益率／1回あたり利益／売れ筋（利益×製品の24h販売数）
- レシピは `site/recipes.json`（出典は NOTICE.md）。ゲームの大型アップデートでレシピが変わったら
  `tools/build_recipes.py` で作り直してください。コンボでしか出ない品のレシピは、元レシピのコンボとして計算します

## 韓国比較と予測

「🇰🇷 韓国比較」タブで、韓国版（2025/11/19発売）とグローバル版（2026/10/5発売）を **発売からの週数** でそろえて比べ、
品目ごとの見立て（上がりそう／天井圏／下がりそう／横ばい、期間、確度、根拠）を表示します。

- 韓国の週平均：aeid.gg（韓国ワールド取引所、発売18週目以降のみ）
- 韓国の発売直後（1〜12週目）：DCInside・Inven の書き込みにある価格（出典リンク付き。系統的なデータは存在しない）
- グローバルの参考値：aion2.exchange の北米・欧州6サーバー（10/19時点）。自分のサーバーの値は毎時の収集データ
- 元データは [shizukaziye/aion2-market-history](https://github.com/shizukaziye/aion2-market-history) の data/ 。
  `tools/kr_reference.py <dataディレクトリ> site/kr.json` で作り直し、予測は同スクリプト内の FORECAST / OUTLOOK を書き換えて更新

## 設定

- 対象リージョン：リポジトリの Variables に `REGIONS` を設定（既定 `AS`）。カンマ区切りで複数可（例 `AS,NAW`）
- 手動で更新：Actions タブ →「相場を収集して公開」→ Run workflow
- GitHub は60日間リポジトリに動きがないと予約実行を止めます。止まったら Actions タブで再有効化してください

## ローカルで試す（模擬データ）

```sh
python tools/mock_exchange.py 8765 &
python collector/collect.py --base http://127.0.0.1:8765 --nc http://127.0.0.1:8765 --out _site --delay 0
cp -r site/* _site/ && cd _site && python -m http.server 8000
```
